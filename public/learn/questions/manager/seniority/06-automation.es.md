# ¿Cómo pensás la automatización?

> Señal clave para senior: te escalás vos y al equipo a través de automatización.

## Respuesta sólida

Veo a la automatización como un **habilitador clave para calidad y escalabilidad**.

Cada vez que un proceso es repetitivo, propenso a errores o crítico, intento automatizarlo.

Esto incluye **pipelines de CI/CD, testing automatizado en distintos niveles y validaciones** para detectar issues temprano.

También me enfoco en automatizar **tareas operativas** — como monitoring, alertas y workflows de deploy — para reducir la intervención manual y mejorar la confiabilidad.

El objetivo general es aumentar la velocidad de entrega manteniendo consistencia y reduciendo el error humano.

## Tip

Enmarcalo como **velocidad + calidad + confiabilidad**, no "menos trabajo para mí".
