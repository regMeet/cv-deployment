# ¿Cómo asegurás la calidad del código?

> Prácticas concretas, no teóricas.

## Respuesta sólida

> "I rely on **automated testing, code reviews, and clear design principles**. I also prefer **simple, maintainable solutions** over overly complex ones."

## Qué mencionar

- Testing automatizado en múltiples niveles (unit, integration, e2e).
- Code reviews con feedback constructivo.
- Gates de CI/CD.
- Observabilidad — logs, métricas, alertas para detectar issues post-deploy.
- Simplicidad sobre cleverness.
