# Contame sobre un problema desafiante que enfrentaste

> Quieren **pensamiento estructurado + ownership + impacto medible**. Usá STAR.

## Estructura STAR

- **Situation**: contexto claro.
- **Task**: tu responsabilidad.
- **Action**: qué hiciste *vos* (no "el equipo").
- **Result**: impacto medible.

## Ejemplo sólido

> "We had a production issue where API latency spiked from 200ms to 2s under load. I was responsible for identifying the bottleneck. I added distributed tracing, found N+1 queries in a critical endpoint, and redesigned it using batching and caching. We reduced latency by **80%** and stabilized the system under peak traffic."

## Tip

Las métricas son oro. Latencia, costo, throughput, error rate — cualquier cosa cuantificable.
