# How do you ensure code quality?

> Practical practices, not theoretical ones.

## Strong answer

> "I rely on **automated testing, code reviews, and clear design principles**. I also prefer **simple, maintainable solutions** over overly complex ones."

## What to mention

- Automated testing at multiple levels (unit, integration, e2e).
- Code reviews with constructive feedback.
- CI/CD gates.
- Observability — logs, metrics, alerts to catch issues post-deploy.
- Simplicity over cleverness.
