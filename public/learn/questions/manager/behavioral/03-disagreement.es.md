# ¿Cómo manejás desacuerdos con compañeros?

> Quieren **colaboración sin ego**.

## Ejemplo sólido

> "I focus on **data over opinions**. In a disagreement about architecture, I proposed we prototype both approaches and compare performance and complexity. We chose the simpler solution based on evidence."

## Idea clave

El objetivo no es **ganar la discusión** — es **resolver el problema**. Mostrá que podés disagree and commit.

## Mentalidad a transmitir

- Liderar con curiosidad, no con defensa.
- Usar datos/prototipos para resolver desacuerdos técnicos.
- Una vez tomada la decisión, comprometerse del todo — incluso si no era tu opción.
