# Tell me about a challenging problem you faced

> They want **structured thinking + ownership + measurable impact**. Use STAR.

## STAR structure

- **Situation**: clear context.
- **Task**: your responsibility.
- **Action**: what *you* did (not "the team").
- **Result**: measurable impact.

## Strong example

> "We had a production issue where API latency spiked from 200ms to 2s under load. I was responsible for identifying the bottleneck. I added distributed tracing, found N+1 queries in a critical endpoint, and redesigned it using batching and caching. We reduced latency by **80%** and stabilized the system under peak traffic."

## Tip

Metrics = gold. Latency, cost, throughput, error rate — anything quantifiable.
